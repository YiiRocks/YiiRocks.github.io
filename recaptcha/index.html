YiiRocks/reCAPTCHA

recaptcha provides Google reCAPTCHA v2 and v3 widget and server-side validation for your Yii Framework 3 applications.

Configuration

Set your site keys and secret keys via environment variables or directly in config/params.php: 

'yiirocks/recaptcha' => [
    'siteKeyV2' => $_ENV['RECAPTCHA_SITE_KEY_V2'] ?? '',
    'secretV2' => $_ENV['RECAPTCHA_SECRET_V2'] ?? '',
    'siteKeyV3' => $_ENV['RECAPTCHA_SITE_KEY_V3'] ?? '',
    'secretV3' => $_ENV['RECAPTCHA_SECRET_V3'] ?? '',
    'verifyUrl' => 'https://www.google.com/recaptcha/api/siteverify',
    'sendRemoteIp' => false,
    'translation.category' => 'yii3-recaptcha',
],

Once configured, the widget pulls the site key from the registry automatically — no need to call withSiteKey() in your view code.

reCAPTCHA v2 Widget

use YiiRocks\Recaptcha\RecaptchaV2;
use YiiRocks\Recaptcha\RecaptchaV2Theme;
use YiiRocks\Recaptcha\RecaptchaV2Size;
use YiiRocks\Recaptcha\RecaptchaV2Type;

// Site key is pulled from config automatically:
echo RecaptchaV2::widget()
    ->withTheme(RecaptchaV2Theme::Dark)
    ->withSize(RecaptchaV2Size::Normal)
    ->render();

reCAPTCHA v2 Options

  • siteKey ( string, from config ) Explicit site key override. Optional — pulled from config by default
  • theme ( RecaptchaV2Theme ) Light (default) or Dark
  • size ( RecaptchaV2Size ) Normal (default), Compact, or Invisible
  • type ( RecaptchaV2Type ) Image (default) or Audio
  • callback ( string ) JavaScript callback function name on successful verification
  • expiredCallback ( string ) JavaScript callback function name when the CAPTCHA expires
  • errorCallback ( string ) JavaScript callback function name when an error occurs
  • id ( string ) HTML id attribute for the container div
  • jsApiUrl ( string ) Custom JS API URL

reCAPTCHA v3 Widget

The token is fetched on form submit (not on page load), preventing unexpected challenge popups. The form is auto-resolved via closest("form") — no formId needed when the hidden input is inside the form. 

use YiiRocks\Recaptcha\RecaptchaV3;
use YiiRocks\Recaptcha\RecaptchaV3Badge;

// Site key from config, form auto-detected:
echo RecaptchaV3::widget()
    ->withAction('login')
    ->withBadge(RecaptchaV3Badge::BottomRight)
    ->render();

// With explicit form ID (input outside the form):
echo RecaptchaV3::widget()
    ->withFormId('login-form')
    ->withBadge(RecaptchaV3Badge::Hidden)
    ->render();

reCAPTCHA v3 Options

  • siteKey ( string, from config ) Explicit site key override. Optional — pulled from config by default
  • action ( string = 'submit' ) Action name to pass to reCAPTCHA
  • formId ( string ) Explicit form ID. When omitted the form is auto-resolved via closest("form")
  • fieldName ( string = 'g-recaptcha-response' ) Hidden input field name
  • fieldId ( string ) Hidden input field ID
  • badge ( RecaptchaV3Badge ) BottomRight (default), BottomLeft, or Hidden
  • jsApiUrl ( string ) Custom JS API URL
  • translator ( TranslatorInterface ) Translator for the hidden badge legal notice. Pulled from registry if omitted

Validation

Use attributes on your form model properties:

use YiiRocks\Recaptcha\RecaptchaV2Rule;
use YiiRocks\Recaptcha\RecaptchaV3Rule;

class LoginForm
{
    #[RecaptchaV2Rule(
        message: 'The CAPTCHA verification failed.',
        secret: null,
        sendRemoteIp: false,
    )]
    public string $gRecaptchaResponse = '';

    #[RecaptchaV3Rule(
        threshold: 0.5,
        action: 'login',
        message: 'The CAPTCHA verification failed.',
        scoreTooLowMessage: 'The CAPTCHA score is too low.',
        actionMismatchMessage: 'The CAPTCHA action does not match.',
    )]
    public string $gRecaptchaResponseV3 = '';
}

Server-Side Verification

Use RecaptchaClient for manual verification: 

use YiiRocks\Recaptcha\RecaptchaClient;

/** @var RecaptchaClient $client */
$result = $client->verify($token);
$result = $client->verifyV3($token);
$result = $client->verifyWithSecret($token, $secret);

$result->success;     // bool
$result->score;       // ?float (v3 only)
$result->action;      // ?string (v3 only)
$result->errorCodes;  // array
$result->hostname;    // ?string
$result->challengeTs; // ?string

$config = $client->getConfig(); // RecaptchaConfig
