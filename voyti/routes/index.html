The library does not provide a menu model or navigation contract. It only exposes named routes that the host application can use in its own menu, sidebar, or access rules.

The REST API routes below live in their own voyti-routes-api config group (see Quick Start), separate from voyti-routes above — pull that group into your router too if you want the API exposed, and mount it at whatever prefix you like. See REST API for the remaining config options.
